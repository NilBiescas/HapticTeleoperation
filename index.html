Haptic Teleoperation and Learning from Demonstration with the Franka Robotic Arm

A research project exploring real-time robotic control using haptic devices and trajectory learning via Gaussian Mixture Models.

Introduction

Remote Control

Real-time control of a robot using a haptic device allows humans to perform precise tasks in remote or hazardous environments, such as surgery or search and rescue.

Learning from Demonstration

Robots can learn complex manipulation tasks from human demonstrations, enabling them to generalize trajectories to new, dynamic situations without manual programming.

Remote Control

System Architecture

The system connects two PCs via ROS. PC1 handles the Falcon haptic device, while PC2 manages the control node communicating with the Franka Panda via TCP/IP.

PC1 (Falcon) → ROS → PC2 (Control) → Franka Panda
ROS-based system connection diagram.

Control & Feedback

We implemented Cartesian Impedance Control for both position and orientation. Orientation error is handled via quaternion-based calculations.

Cartesian position control details.

Force Feedback

Instead of a dedicated sensor, we estimated external wrench from the robot's internal state. A threshold filter was applied to reduce noise before sending haptic feedback.

Estimated external wrench feedback.

Workspace & Gripper

Clutch Strategy: Hold a button to enable motion, allowing the small Falcon workspace to map to the large robot workspace.

Gripper: Managed via franka_gripper with specific button mappings for open, close, and grasp actions.

Learning from Demonstration

GMM & GMR

We model the joint distribution P(x, v) using Gaussian Mixture Models. Trajectory reproduction is then achieved via Gaussian Mixture Regression, conditioning on the current position.

GMM learning using Expectation-Maximization.

Task-Parameterized GMM

TP-GMM allows the robot to generalize demonstrations to different reference frames (task parameters), improving extrapolation in changing environments.

Generalization experiment with 8 demonstrations.
